# Khushboo Saini — Portfolio

A responsive, dark creative developer portfolio built with React, Vite, Tailwind CSS v4, Framer Motion and Lucide icons.

## Run locally

```bash
npm install
npm run dev
```

Open the local URL printed by Vite (normally http://localhost:5173).

## Production build

```bash
npm run build
npm run preview
```

## Personalize before publishing

1. In `src/App.jsx`, replace `YOUR_EMAIL@example.com` with the email address you want to publish.
2. Replace the LinkedIn placeholder (`https://www.linkedin.com/`) with your exact profile URL.
3. Review the project descriptions, especially Aven and Rock One Solutions, and add live demo links where available.
4. Confirm the internship date/status and education details are still accurate before publishing.
5. Add a downloadable resume link if you want one.

## Deploy

The project is a standard Vite app and can be deployed to Vercel or Netlify. Build command: `npm run build`; output directory: `dist`.
